**Solstice Court** is an original tactical card duel game built with pure HTML5 Canvas 2D, modular ES JavaScript, and procedural Web Audio (zero external assets or network requests). Master four geometric suits (Solar, Lunar, Verdant, Imperial), read and counter the Astral Automaton's telegraphed intents, and chain Harmonic Pairs, Eclipse Chains, and Solstice Convergences across three difficulty tiers.

## Run it

```sh
node serve.ts
# Then open http://127.0.0.1:8080 in Chrome
# To build the make.fun submission output locally:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
